# Hand-over report — M0 + M1 — 2026-10-29

## 1. Summary
M0 (foundation) and M1 (core 2D viewer) are implemented, tested and committed. The app is a hardened Electron 45 /
React 19 / Cornerstone3D 5.14 viewer that opens files, folders, DICOMDIR and encrypted ZIPs. Clinical math lives in the
pure-TypeScript `dicom-core` package, tested against analytic phantoms: IPP sorting, spacing and tilt checks, orientation
labels, VOI/LUTs and Turkish character sets. The independent verifier failed the first pass with 6 blocking gaps,
including two real bugs (HiDPI 1:1 zoom; Modality LUT lost after cache eviction). All were fixed; the second pass is
**PASS**.
**OS actually run on:** Windows 11 Home x64 (local). **CI:** not run (no GitHub remote). macOS is UNVERIFIED.

## 6. Known issues, limitations, risks
- **Not verified:**
  - CI and macOS never run (R-007).
  - Drag & drop and the OS clipboard not E2E-verified.
- **Not implemented:**
  - Concatenation merge (R-018).
  - Padding pixels are not forced to black.
  - Presentation LUT INVERSE not asserted.
  - Tag browser gives no "truncated" notice (R-021).
- **Upstream Cornerstone 5.14 defects, worked around and each covered by a test (R-016):**
  - VOI LUT Function truncated to its first character.
  - Deflated datasets not parsed.
  - Anisotropic `imageToWorldCoords`.
  - Silent decode failures.
- **Performance:** scrolling while prefetch is still decoding is slower (R-017).
- **UX:** corner text has low contrast over bright image regions (R-020).
